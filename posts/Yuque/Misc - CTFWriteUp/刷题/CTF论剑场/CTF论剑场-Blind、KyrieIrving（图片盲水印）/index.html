CTF论剑场-Blind、KyrieIrving（图片盲水印）

配置环境：（以下命令基于python2）

方法一：（https://www.cnblogs.com/zaqzzz/p/9478086.html）

Windows下基于Python的OpenCV的安装

1.配置Python环境（略）

2.在cmd下，输入pip install opencv-python并等待下载安装完成。

3.在cmd下，输入Python进入交互模式，然后输入import cv2，没有报错即配置成功

如果在运行脚本的过程中，提示没有安装matplotlib，那就还需要安装matplotlib

在cmd下键入命令pip install matplotlib，并等待安装完成即可

方法二：（https://blog.csdn.net/u010128736/article/details/52713204）

（https://blog.csdn.net/cairencong/article/details/82709317）

Windows下Python安装OpenCV详细步骤

1.配置Python环境（略）

2.安装Numpy

①安装pip

注：pip是一个以Python计算机程序语言写成的软件包管理系统，它可以安装和管理软件包，另外不少的软件包也可以在”Python软件包索引”(英语：Python Package Index,简称PyPI)中找到。

若上面安装出现没找到python，先安装pip。输入python -m pip install -U pip

注：安装在D:\Python27\Scripts目录下，可以看到pip.exe。黑框操作时，只有当cd进入这个目录，我们才能使用pip命令，这明显不是我们想要的效果。我们想黑框操作时，在任意目录下都可以使用pip命令；因此需要将D:\Python27\Scripts添加到Path。若Python版本不在Python 2 >=2.7.9 or Python 3 >=3.4该范围，则需要单独安装pip。


先下载get-pip.py

执行命令：curl https://bootstrap.pypa.io/get-pip.py -o get-pip.py


然后运行该脚本文件进行安装 python get-pip.py
pip可用

完后将pip的路径加到PATH里，例如”C:\Python27\Scripts”

②安装numpy

现在开始安装numpy，打开cmd，输入pip install numpy

测试是否安装成功：

3.安装opencv

在官网自行下载，这里下载的是opencv2.4.10安装。

①复制cv2.pyd

将opencv安装程序解压后，在”\opencv\build\python\2.7\x64”或”\opencv\build\python\2.7\x86”（根据python版本）文件夹中找到cv2.pyd”，复制到Python安装目录的”C:\Python27\Lib\site-packages”文件夹中。

测试：

若使用一下代码未报错，则安装成功：

import cv2

import numpy as np

write up：

首先先声明两点：

①盲水印的加密有两种方式，怎么说呢，用其中一个加上水印，用另一个解不开。

②两种盲水印的解密命令也不一样

下载地址：

https://github.com/linyacool/blind-watermark

https://github.com/chishaxie/BlindWaterMark

盲水印的题目有如下特点：通过foremost分离可以得到两张图片，这两个图片命名不同（也有可能相同），但图片极其相似，肉眼看起来长得是一样的。

这时候应该想到隐写里的提取盲水印

那就开始吧！

BlindWaterMark-master–bwm.py

blind-watermark-master–decode.py

python decode.py –original –image –result

首先尝试：BlindWaterMark-master–bwm.py

将图片放在相同的目录下，由于我们添加了环境变量，所以在任何目录下都可以执行命令

语法：

python bwn.py（解密脚本）decodeblind.png（原图片） blind_blind.png（foremost分离得到的图片）result.png（分离出来的水印）

例如：

python bwm.py decode blind.png blind_blind.png result.png

执行命令：

打开result.png

加密与解密命令不对应，解密失败！

尝试：

blind-watermark-master–decode.py

语法：

python decode.py –original –image –result

即：

python decode.py –original <原文件> –image <foremost分离得到的文件> –result <盲水印>

例如：

python decode.py –original blind.png –image blind_blind.png –result result1.png

执行命令：

未报错就是执行成功！

打开result1.png

得到flag：

flag{s0rryIAmBlind}
