2019NCTF-小狗的秘密（wireshark、RGB Python脚本）

链接：https://pan.baidu.com/s/1qSCtZhoCHYIxIzjDeUMpzA
提取码：vlrz

打开文件后在筛选框里输入“http contains html”来进行筛选（看别人wp再知道要这样做的，当然，一开始你只能一个一个找）

发现其中的一条html中十分奇特

打开它

直接追踪http流

出现了一些坐标，应该是RGB的颜色坐标，用Python脚本直接转换

Python脚本如下：（请将坐标保存为1.txt）

#-- coding:utf-8 -- 

from PIL import Image 

import re 

x = 500 #x坐标 通过对html里的行数进行整数分解 

y = 100 #y坐标 x*y = 行数 

im = Image.new(“RGB”,(x,y))#创建图片 

file = open(‘1.txt’) #打开rbg值文件 

#通过一个个rgb点生成图片 

for i in range(0,x): 

    for j in range(0,y):

        line = file.readline()#获取一行 

        rgb = re.split(“,|(|)“,line)#分离rgb 

        rgb = filter(None, rgb)#过滤空格 

        im.putpixel((i,j),(int(rgb[0]),int(rgb[1]),int(rgb[2])))#rgb转化为像素 

im.show()

Python和其他语言不一样，Python是依照缩进来确定代码块，不然会出现：IndentationError: expected an indented block的错误
