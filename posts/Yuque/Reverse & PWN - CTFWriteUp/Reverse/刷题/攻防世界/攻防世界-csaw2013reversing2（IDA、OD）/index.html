攻防世界-csaw2013reversing2（IDA、OD）

将程序下载并载入到IDA中，直接找到main函数，按下F5查看伪代码：

我们可以尝试运行一下程序，看看程序能给我们什么提示：

无论你点击的是中止、重试还是忽略，都会直接退出程序；而且窗口上有flag的字样，但是显示出来的内容却是乱码，真的很有意思。

我们回头看伪代码：

int __cdecl __noreturn main(int argc, const char **argv, const char **envp)

{

int v3; // ecx

CHAR *lpMem; // [esp+8h] [ebp-Ch]

HANDLE hHeap; // [esp+10h] [ebp-4h]

hHeap = HeapCreate(0x40000u, 0, 0);

lpMem = (CHAR *)HeapAlloc(hHeap, 8u, MaxCount + 1);

memcpy_s(lpMem, MaxCount, &unk_409B10, MaxCount);

if ( sub_40102A() || IsDebuggerPresent() )

{

__debugbreak();

sub_401000(v3 + 4, (int)lpMem);

ExitProcess(0xFFFFFFFF);//结束进程

}

MessageBoxA(0, lpMem + 1, “Flag”, 2u);//弹出窗口

HeapFree(hHeap, 0, lpMem);

HeapDestroy(hHeap);

ExitProcess(0);//结束进程

}

真的很有意思，程序在运行的过程中并没有执行if语句，而是直接跳过它，执行弹出窗口的内容。

我们再回头来看IDA：

关注下半部分，发现程序中有两个可以弹出窗口的地方：（flag）

我们来画一下当前程序的走向：（用红色粗线笔来表示）（图时错的）

上图错的原因：误把绿色箭头当做当前程序的执行顺序（IDA只是假设运行了if语句会怎么样，其实并没有运行），事实上，绿色箭头表示的是“满足条件（yes）”，红色箭头表示“不满足条件（no）”。正确的图应该为：

程序的运行过程不要受IDA流程图干扰！！！

那我们先尝试一下，让程序执行if语句会怎么样，将程序载入到OD中：

老规矩，先智能搜索一下：

发现两个字符串“flag”

双击点进去第一个：

双击点进去第二个：

在周围找if语句的跳转指令（由于if语句中包含IsDebuggerPresent的字符串，那我们就去找他）：

上面的jnz跳转指令应该就是if语句的判断，若不满足if条件就不跳转（在此程序中没有执行跳转（不满足条件），因此执行je short 00FF10B9）

注意到：

再看：je short 00FF10B9，

它跳转到了第一个flag窗口（相较于IDA而言，在OD中从上往下是第二个），因为我们的目标是第一个flag窗口（即OD中的第二个），nop掉。

百度int 3：程序暂停（有时候会阻碍OD的单步调试，nop掉吧）

继续往下看：

jmp short 00FF10EF直接跳转到了if语句里的退出程序，我们让他跳转到第一个flag窗口，修改为：

jmp short 00FF10B9

保存修改，导出exe
