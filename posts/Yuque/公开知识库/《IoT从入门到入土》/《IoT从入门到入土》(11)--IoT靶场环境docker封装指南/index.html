《IoT从入门到入土》(11)–IoT靶场环境docker封装指南

  • 前置基础：需掌握docker、dockerfile、docker-compose的最基本使用方法

在本篇文章中，我将对IoT模拟环境的docker封装分为两种方式 – 以firmAE、firmadyne、firmware-analysis-plus为代表的一键模拟的封装；以hook、patch（qemu-system）为代表的手动模拟环境的封装。并在文章最后列出了一些注意事项。

  • firmAE ： https://github.com/pr0v3rbs/FirmAE
  • firmadyne ： https://github.com/firmadyne/firmadyne
  • firmware-analysis-plus ： https://github.com/liyansong2018/firmware-analysis-plus

执行如下两条命令即可封装：

  • docker-compose -f docker-compose-system.yml build ：开始封装环境（docker image）
  • docker-compose -f docker-compose-system.yml up ：启动已经封装好的环境（create docker container）

之后需要导出docker image：sudo docker save -o 【docker镜像名称】.tar 【docker镜像名称】:lastest（受IoT靶场限制，这里tar文件的docker镜像名称不能更改）。
